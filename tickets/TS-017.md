## User Story

En tant que Marie, je veux que Trackshield me dise précisément quel tracker m'a suivi et pourquoi, afin de comprendre concrètement ce qui a été collecté sur moi.

## Contexte

Aujourd'hui le détecteur PII tente de deviner la nature d'une donnée par sa forme (regex). C'est insuffisant : un ID de clic Google (`gclid`) ou un identifiant Facebook (`fbclid`) sont des paramètres documentés publiquement — on sait exactement ce qu'ils sont et ce qu'ils permettent de faire. Les reconnaître par leur nom donne une certitude maximale et permet d'afficher un message précis à l'utilisateur.

## Critères d'acceptation

- [ ] Les paramètres URL suivants sont détectés et nommés : `fbclid`, `gclid`, `ttclid`, `_ga`, `_gid`, `utm_source`, `utm_medium`, `utm_campaign`, `mc_eid`, `msclkid`
- [ ] Chaque paramètre connu produit un label humain précis (ex: `gclid` → "Identifiant de clic Google Ads")
- [ ] Chaque paramètre connu produit une description d'impact (ex: "Google sait que tu as cliqué sur une pub et peut lier cette visite à ton profil")
- [ ] Les détections issues de paramètres connus ont une propriété `certainty: 'high'` dans `PiiDetection`
- [ ] Les détections issues de regex seules ont `certainty: 'low'`
- [ ] Les tests couvrent tous les paramètres connus (≥10 cas)

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer / modifier :**
- `apps/plugin/src/background/known-params.ts` — dictionnaire `KNOWN_PARAMS: Record<string, { label: string, description: string, type: PiiType }>` pour les 10+ paramètres documentés
- `apps/plugin/src/background/pii-detector.ts` — scanner les query params avant les regex, appliquer `certainty`
- `packages/shared-types/src/domain/pii.types.ts` — ajouter `certainty: 'high' | 'low'` à `PiiDetection`
- `apps/plugin/tests/pii-detector.test.ts` — couvrir les paramètres connus

**Patterns à respecter :**
- `known-params.ts` est une map statique, aucune dépendance externe
- La détection par paramètre connu est prioritaire sur les regex
- Types partagés via `@trackshield/shared-types` uniquement

**Dépend de :** Aucune dépendance bloquante
