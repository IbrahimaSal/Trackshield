## User Story

En tant que Thomas, je veux accéder au rapport d'audit complet depuis le popup afin de l'exporter ou le partager avec mon client directement après une inspection.

## Contexte

`ReportView.tsx` affiche "Vue en construction". Cette vue appelle l'endpoint `/report` de FastAPI (TS-006) pour récupérer le rapport structuré et l'afficher. Elle doit aussi proposer un export HTML. Thomas est le persona principal de cette vue — il a besoin de données précises et exportables.

## Critères d'acceptation

- [ ] La vue affiche le score RGPD, la liste des trackers et PII détectés du site courant
- [ ] Le rapport est généré en moins de 5 secondes après le clic sur "Générer"
- [ ] Un état de chargement est visible pendant la génération
- [ ] Le bouton "Télécharger HTML" génère un fichier `.html` téléchargeable
- [ ] Un message d'erreur s'affiche si l'analyzer est indisponible (mode dégradé)
- [ ] Les valeurs PII sont masquées dans le rapport affiché

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer / modifier :**
- `apps/plugin/src/popup/views/ReportView.tsx` — remplacer le stub

**Patterns à respecter :**
- Composant fonctionnel React, props typées
- L'appel à l'API se fait via `fetch` vers `${apiUrl}/report` (URL lue depuis chrome.storage.local)
- État local : `useState` pour `loading`, `report`, `error` — pas de store global pour le rapport
- Le téléchargement HTML utilise `URL.createObjectURL(new Blob([htmlContent], { type: 'text/html' }))`
- Gestion du mode dégradé : si l'API est indisponible, afficher les données locales du session store

**Dépend de :** TS-006 — Route rapport FastAPI
