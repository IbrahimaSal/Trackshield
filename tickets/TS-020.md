## User Story

En tant que Marie, je veux savoir quand un identifiant stocké dans mon navigateur par un site est transmis à un tiers, afin de comprendre comment je suis tracée entre différentes sessions.

## Contexte

Les identifiants publicitaires les plus persistants ne transitent pas dans les URLs — ils sont stockés dans les cookies ou le localStorage, puis inclus silencieusement dans des requêtes réseau. Sans croiser ce qui est stocké avec ce qui est envoyé, on ne peut pas dire "cet identifiant stocké par Twitter il y a 3 jours vient d'être transmis à Doubleclick". Ce ticket permet de lire ce que les sites stockent dans le navigateur et de détecter quand ces valeurs quittent le navigateur vers des tiers.

## Critères d'acceptation

- [ ] Le content script lit les clés/valeurs de `localStorage` et les cookies accessibles depuis la page
- [ ] Les valeurs connues sont transmises au background via `chrome.runtime.sendMessage({ type: 'STORED_VALUES', values: Map<string,string> })`
- [ ] Si une requête réseau contient une valeur stockée, la détection est marquée `certainty: 'high'` avec `source: 'storage'`
- [ ] Seules les valeurs de longueur ≥ 8 caractères sont prises en compte (éviter les faux positifs sur valeurs triviales)
- [ ] Les valeurs stockées ne sont jamais persistées dans `chrome.storage` — mémoire uniquement
- [ ] Les tests couvrent : valeur localStorage → requête avec valeur → détection certaine

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer / modifier :**
- `apps/plugin/src/content/form-observer.ts` — étendre pour lire `localStorage` et `document.cookie` à l'initialisation + sur mutation
- `apps/plugin/src/background/index.ts` — stocker les valeurs connues par tabId (fusionner avec la Map des formulaires de TS-018)
- `packages/shared-types/src/domain/pii.types.ts` — ajouter `source?: 'form' | 'url' | 'storage'` à `PiiDetection`

**Patterns à respecter :**
- Ne jamais lire les cookies `HttpOnly` (inaccessibles par JS de toute façon)
- Zéro persistance des valeurs stockées (mémoire uniquement)
- Fusionner avec la Map de TS-018, pas de Map séparée

**Dépend de :** TS-018 (infrastructure du pont content script → background)
