**Commande :**
```bash

```


## Impact

Le plugin ne compile pas. Les champs `certainty`, `source`, `label`, `description` ajoutés par TS-017
dans `packages/shared-types/src/domain/pii.types.ts` ont été revertés.
`pii-detector.ts` et les tests du plugin référencent ces champs → typecheck bloqué.
