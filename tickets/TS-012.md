## User Story

En tant que le plugin, je veux comparer chaque URL de requête à des listes de trackers connus compilées afin de détecter les domaines de tracking en temps réel.

## Contexte

Le matcher (`src/matcher.ts`) et le script de compilation (`scripts/compile-lists.ts`) sont implémentés, mais les fichiers JSON de données sont absents (seulement un `.gitkeep`). Sans ces fichiers, `TrackerMatcherService.match()` retourne toujours `null` — aucun tracker n'est jamais détecté. C'est un blocage P0 direct sur la fonctionnalité principale.

## Critères d'acceptation

- [ ] `packages/tracker-lists/data/easylist.json` existe et fait > 100KB
- [ ] `packages/tracker-lists/data/disconnect.json` existe et fait > 50KB
- [ ] `packages/tracker-lists/data/easyprivacy.json` existe et fait > 50KB
- [ ] `TrackerMatcherService.match('https://www.google-analytics.com/collect')` retourne un match non-null
- [ ] `TrackerMatcherService.match('https://example.com/page')` retourne null
- [ ] Le script `compile-lists.ts` peut être relancé pour mettre à jour les données

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer :**
- `packages/tracker-lists/data/easylist.json` — généré par le script
- `packages/tracker-lists/data/disconnect.json` — généré par le script
- `packages/tracker-lists/data/easyprivacy.json` — généré par le script

**Étapes :**
1. Analyser `scripts/compile-lists.ts` pour comprendre les sources et le format de sortie attendu
2. Exécuter le script via `pnpm --filter @trackshield/tracker-lists compile` (ou adapter si la commande diffère)
3. Vérifier que les JSON générés sont valides et non vides
4. Si le script nécessite des corrections mineures pour fonctionner, les apporter

**Patterns à respecter :**
- Les JSON générés doivent respecter le type `TrackerList` défini dans `src/types.ts`
- Ne pas committer des fichiers JSON > 10MB (compresser si nécessaire ou filtrer les entrées)
- Ajouter une entrée dans `turbo.json` si le script doit être exécuté dans le pipeline de build

**Dépend de :** Aucune dépendance bloquante
