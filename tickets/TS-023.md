## User Story

En tant que Marie, je veux que le popup Trackshield ressemble aux maquettes validées — fond sombre, typographie DM Sans, et un état visuel positif quand le site est propre — afin de faire confiance à l'outil dès le premier regard.

## Contexte

Revue visuelle du 2026-04-03 : comparaison entre `specs/trackshield-screens/01-badge-popup.html` et le popup en prod. Trois divergences bloquantes identifiées. La plus critique est le fond blanc : le popup s'affiche sur fond browser blanc au lieu du `#0E1118` des specs, rendant tout le texte `text-white` illisible. La police système est utilisée à la place de DM Sans / DM Mono. Et quand un site est "propre" (score A, 0 tracker), le popup n'affiche pas l'encart de réassurance prévu dans les specs.

## Critères d'acceptation

- [ ] Le fond du popup est `#0E1118` (quasi-noir) — plus de fond blanc browser visible
- [ ] La police DM Sans est utilisée pour le texte courant, DM Mono pour les valeurs masquées et l'URL
- [ ] Quand score A **et** 0 trackers détectés : affichage d'un encart vert *"Ce site respecte votre vie privée"* à la place de la section trackers vide
- [ ] Les trois états visuels (site sûr, trackers détectés, PII exposées) correspondent aux maquettes de `specs/trackshield-screens/01-badge-popup.html`
- [ ] Aucune régression sur les tests existants (88 tests verts)

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer / modifier :**
- `apps/plugin/src/popup/index.css` — ajouter `background: #0E1118; color: #EEF0F8;` sur `body` + `@import` Google Fonts DM Sans / DM Mono
- `apps/plugin/src/popup/views/PopupMain.tsx` — ajouter le composant `OkBox` quand `trackers.length === 0 && piis.length === 0`
- `apps/plugin/src/popup/components/blocks/OkBox.tsx` — nouveau composant (vert, icône checkmark, message)

**Specs de référence :**
```
specs/trackshield-screens/01-badge-popup.html  — maquette popup safe + danger
specs/trackshield-screens/tokens.css           — tokens couleurs et typographie
```

**Tokens à respecter (depuis tokens.css) :**
```
--bg:      #090B11   (fond page)
--surface: #0E1118   (fond popup)
font: DM Sans 300/400/500/600 + DM Mono 400/500
--ok:      #1FCC7A   (vert)
--ok-bg:   rgba(31,204,122,0.10)
```

**OkBox — structure cible :**
```tsx
// Encart affiché quand score A + 0 trackers + 0 piis
<div className="rounded-lg p-3 text-center" style={{ background: 'rgba(31,204,122,0.10)', border: '1px solid rgba(31,204,122,0.20)' }}>
  {/* icône checkmark SVG */}
  <div className="text-xs text-severity-ok font-medium mt-1.5">
    Ce site respecte votre vie privée
  </div>
</div>
```

**Import fonts (index.css) :**
```css
@import url('https://fonts.googleapis.com/css2?family=DM+Sans:wght@300;400;500;600&family=DM+Mono:wght@400;500&display=swap');
```

**Patterns à respecter :**
- Composant fonctionnel React uniquement
- Pas de class component
- Pas de modification de la logique de détection ou des stores

**Dépend de :** Aucune dépendance bloquante
