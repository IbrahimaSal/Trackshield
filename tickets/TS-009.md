## User Story

En tant que Marie, je veux consulter la liste des alertes PII déclenchées pendant ma session afin de revoir ce qui a été détecté et décider si je veux en savoir plus.

## Contexte

`AlertsView.tsx` affiche "Vue en construction". Cette vue est l'historique des alertes de la session — les notifications que Marie a peut-être ignorées ou manquées. Le alerts store contient déjà les données nécessaires.

## Critères d'acceptation

- [ ] Les alertes sont affichées par ordre chronologique inverse (la plus récente en premier)
- [ ] Chaque alerte indique : type de donnée, domaine destinataire, horodatage
- [ ] Le niveau de criticité est visible visuellement (rouge = critique, orange = avertissement)
- [ ] Un bouton "Effacer les alertes" vide le store d'alertes
- [ ] Un message "Aucune alerte pour cette session" s'affiche si le store est vide

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer / modifier :**
- `apps/plugin/src/popup/views/AlertsView.tsx` — remplacer le stub

**Patterns à respecter :**
- Composant fonctionnel React, props typées
- Utiliser `useAlertsStore()` pour lire `alerts` et l'action `clearAlerts`
- Réutiliser `PiiTag` pour le type de donnée et `MaskedValue` pour la valeur
- Trier les alertes par `timestamp` décroissant côté composant
- Types depuis `@trackshield/shared-types`

**Dépend de :** Aucune dépendance bloquante (alerts.store est implémenté)

## Hors scope de ce ticket

- Persistance des alertes entre sessions (V2)
- Filtrage par type d'alerte
- Action "Ignorer ce domaine" (V2)
