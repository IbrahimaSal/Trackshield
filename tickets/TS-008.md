## User Story

En tant que Marie, je veux voir quelles données personnelles ont été envoyées et à qui afin de comprendre concrètement ce qui quitte mon navigateur à mon insu.

## Contexte

`FluxView.tsx` affiche "Vue en construction". C'est LA vue différenciante de Trackshield — la cartographie donnée → destinataire. Elle montre des lignes du type : `+336••••5678 [TEL] → pixel.facebook.com (Meta Inc.)`. Le session store contient déjà les `piis` nécessaires.

## Critères d'acceptation

- [ ] Chaque PII détectée est affichée avec sa valeur masquée, son type coloré, et le domaine destinataire
- [ ] Les détections sont groupées par domaine destinataire
- [ ] Un message "Aucune donnée transmise détectée" s'affiche si `piis` est vide
- [ ] Les valeurs PII sont toujours masquées — jamais affichées en clair
- [ ] Un bouton "← Retour" ramène à la vue principale

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer / modifier :**
- `apps/plugin/src/popup/views/FluxView.tsx` — remplacer le stub

**Patterns à respecter :**
- Composant fonctionnel React, props typées
- Utiliser `useSessionStore()` pour lire `piis`
- Réutiliser `PiiLine` et `PiiTag` (`components/domain/`) pour l'affichage
- Réutiliser `MaskedValue` (`components/primitives/`) pour les valeurs masquées
- Grouper par `pii.destination` via `reduce` ou `Map` — pas de lib externe
- Types depuis `@trackshield/shared-types`

**Dépend de :** Aucune dépendance bloquante (session.store, PiiLine, PiiTag, MaskedValue sont déjà implémentés)
