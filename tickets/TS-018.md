## User Story

En tant que Marie, je veux savoir avec certitude quand une donnée que j'ai moi-même saisie (email, téléphone) quitte mon navigateur, afin de comprendre exactement ce qui a été partagé à mon insu.

## Contexte

Un numéro de téléphone détecté par regex dans une URL peut être un faux positif — c'est une séquence de chiffres, pas forcément *mon* numéro. En revanche, si l'utilisateur tape son email dans un formulaire et qu'on retrouve cet email dans une requête réseau vers un tiers, la certitude est absolue. Le content script observe les formulaires ; le background intercepte les requêtes. Il faut un pont entre les deux pour croiser ces informations.

## Critères d'acceptation

- [ ] Quand l'utilisateur saisit un email ou un téléphone dans un formulaire, le content script le transmet au background via `chrome.runtime.sendMessage`
- [ ] Le background stocke ces valeurs en mémoire (par tabId) comme "données connues de l'utilisateur"
- [ ] Si une requête réseau contient une valeur connue, la détection est marquée `certainty: 'high'` avec `source: 'form'`
- [ ] Les valeurs stockées sont effacées à la navigation (nouveau chargement de page)
- [ ] Aucune valeur saisie n'est persistée dans `chrome.storage` — mémoire uniquement
- [ ] Les tests couvrent : saisie email → requête avec email → détection certaine

## Périmètre technique (pour l'agent /dev)

**Fichiers à créer / modifier :**
- `apps/plugin/src/content/form-observer.ts` — détecter les champs email/tel et envoyer les valeurs au background via `chrome.runtime.sendMessage({ type: 'FORM_VALUE', value, fieldType })`
- `apps/plugin/src/background/index.ts` — écouter `chrome.runtime.onMessage` pour stocker les valeurs de formulaire par tabId dans un `Map<number, Set<string>>`
- `apps/plugin/src/background/pii-detector.ts` — accepter un paramètre optionnel `knownValues: Set<string>` pour comparer les détections et élever la certitude
- `packages/shared-types/src/domain/pii.types.ts` — ajouter `source?: 'form' | 'url'` à `PiiDetection`

**Patterns à respecter :**
- Zéro persistance des données saisies (mémoire uniquement, Map vidée au `tabs.onUpdated loading`)
- Le content script ne stocke rien — il transmet et oublie
- Types partagés via `@trackshield/shared-types` uniquement

**Dépend de :** TS-017 (pour le champ `certainty` dans `PiiDetection`)
